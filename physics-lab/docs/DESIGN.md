# Three.js 网页物理实验室 —— 设计文档

> 版本：v1.0（2026-11-01）
> 目标：在浏览器中呈现一间 3D 物理实验室，提供**全学科（力、光、电、波、热）实验设备**，
> 用户通过网页操作设备、改变参数、测量并记录数据，完成完整的探究式物理实验。

---

## 1. 调研结论 → 设计要点（融汇）

### 1.1 PhET 式交互设计（探究式学习核心）
| PhET 设计原则 | 本平台落地方式 |
|---|---|
| 即时反馈（drag & see） | 拖拽设备/滑杆调参后 1 帧内可见变化；光路、轨迹、读数实时更新 |
| 隐性量显性化（make invisible visible） | 力矢量箭头、速度矢量、电场线、光线、波的剖面、等势面全部可视化 |
| 鼓励试错 | 「重置本设备」按钮随处可见；全局重置不惩罚 |
| 场景即界面（scene as interface） | 3D 设备本体可点击/拖拽，同时保留 DOM 面板做精确数值输入 |
| 简洁、少即是多 | 每个实验台聚焦一个主题；属性面板只露出与本设备相关的参数 |
| 记录与反思 | 内置数据表 + CSV 导出 + 绘图，支持"预测—观察—解释"流程 |

### 1.2 真实实验室建设规范（GB/JY 类标准）
- **功能分区**：实验室划分为力学区、光学区（含暗室光学平台）、电学区、波学区、热学区与中央演示台；仪器室/准备间概念映射为"设备仓库面板"。
- **台面高度 0.75–0.85 m**，岛式学生台布局 → 场景中各实验台高度取 0.78 m。
- **安全要素**：低压安全电源（≤24V）、护目镜挂架、灭火器、急救箱、洗眼器、警示标牌 → 3D 场景中建模呈现并计入环境细节。
- **采光**：光学区可遮光（本平台用"关灯"模式模拟暗室）。

### 1.3 技术选型
- **渲染**：Three.js 0.160（本地 vendored ESM，无 CDN 依赖）。
- **刚体动力学**：cannon-es 0.20（纯 JS、维护活跃、API 与 Three 系统天然映射；斜面、抛体、碰撞、牛顿摆足够；精确单摆/弹簧用解析积分而非引擎，保证数值精度）。
- **光学**：自研 2D 平面光线步进（球面镜/透镜用解析折射公式，逐段折线渲染 TubeGeometry），因为只在一个光学台上发生，成本可控、精度高。
- **电路**：自研改进节点分析法（MNA），支持电压源、电阻、灯泡、开关、变阻器；实时求解 I/U。
- **水波**：基于 Huygens-Fresnel 两源干涉解析场（双缝/双源），顶点位移渲染。
- **热学**：能量守恒解析模型 + 实时温度曲线。

**精确仿真优先用解析/半解析模型，cannon-es 只负责"真实感"刚体交互**——这是物理正确性与体验的平衡点（PhET 同样不追求全物理引擎化）。

## 2. 平台架构

```
physics-lab/
├── index.html                  # 单页入口
├── css/style.css               # UI 面板样式
├── js/
│   ├── core/
│   │   ├── App.js              # 应用生命周期：init/loop/dispose
│   │   ├── EventBus.js         # 全局事件（设备增删、仿真 tick、数据记录）
│   │   └── PhysicsLoop.js      # 固定步长仿真循环（dt=1/120，子步进渲染插值）
│   ├── scene/
│   │   ├── LabScene.js         # 房间、地面、灯光、阴影
│   │   ├── Benches.js          # 五大分区实验台 + 演示台 + 安全设施
│   │   └── CameraRig.js        # OrbitControls + 分区视角预设 + 飞入动画
│   ├── equipment/
│   │   ├── EquipmentBase.js    # 所有设备基类：mesh/params/update/serialize/聚焦
│   │   ├── registry.js         # 设备注册表（id → 工厂），新增设备零侵入
│   │   ├── mechanics/          # Pendulum, NewtonsCradle, InclinePlane, ProjectileLauncher, SpringOscillator
│   │   ├── optics/             # OpticalBench: LightSource, ConvexLens, ConcaveLens, PlaneMirror, CurvedMirror, Screen, Prism
│   │   ├── electricity/        # CircuitBench（组件: 电池/开关/电阻/灯泡/变阻器/导线）
│   │   ├── waves/              # RippleTank（双源干涉）
│   │   └── thermal/            # Calorimeter（混合法测比热容）
│   ├── experiments/
│   │   └── guides.js           # 每个实验的指导：目的/器材/步骤/思考题/预期结果
│   ├── ui/
│   │   ├── UI.js               # 面板总装
│   │   ├── EquipmentPanel.js   # 设备仓库（按学科分类，点击生成到台面）
│   │   ├── PropertyPanel.js    # 选中设备的参数编辑（滑杆+数值）
│   │   ├── GuidePanel.js       # 实验指导书
│   │   ├── DataPanel.js        # 数据表 + CSV 导出 + 绘图（Canvas 2D）
│   │   └── Toolbar.js          # 顶部工具栏：播放/暂停/重置/暗室模式/保存/加载
│   └── utils/
│       ├── selection.js        # Raycast 拾取、拖拽移动（贴台面约束）
│       ├── helpers.js          # 矢量箭头、标签 Sprite、刻度纹理生成
│       └── serializer.js       # 场景保存/加载（JSON → localStorage/文件）
├── vendor/  three.module.js, cannon-es.js
└── docs/    DESIGN.md（本文档）
```

**核心抽象**：`EquipmentBase` —— 每个设备是自包含对象：`build()` 建 mesh、`paramsSchema()` 声明可调参数（驱动属性面板自动生成 UI）、`update(dt)` 仿真步进、`getReadouts()` 输出实时读数、`serialize()/deserialize()` 支持保存。新增设备 = 继承基类 + 注册，UI 全自动。

## 3. 设备清单（"全部物理实验设备"覆盖矩阵）

### 力学区（力学实验台 ×2）
| 设备 | 实验内容 | 可调参数 | 可测量 |
|---|---|---|---|
| 单摆装置 | 重力加速度测量 | 摆长 L、摆角 θ₀、重力 g、阻尼 | 周期 T（秒表/光电门） |
| 牛顿摆 | 动量守恒演示 | 球数、拉起球数、弹性系数 | 碰撞过程速度 |
| 斜面滑块 | 滑动摩擦因数测量 | 倾角、μ、质量、初速 | 加速度 a、摩擦力 |
| 平抛运动发射器 | 平抛/斜抛轨迹研究 | 初速 v₀、仰角、发射高度 | 轨迹、射程、时间 |
| 弹簧振子 | 简谐振动与 T-m-k 关系 | k、m、振幅、阻尼 | 周期、能量曲线 |

### 光学区（光学平台，支持暗室模式）
| 器件 | 功能 |
|---|---|
| 光源（点/激光/3线/5线） | 发散/会聚光束 |
| 凸透镜、凹透镜 | 焦距可调，实时成像光路 |
| 平面镜 | 反射光路 |
| 凸面镜/凹面镜 | 曲率可调 |
| 光屏 | 承接实像 |
| 三棱镜 | 最小偏向角与色散（彩虹光路） |
实测：凸透镜成像规律（u>2f/f<u<2f/u<f）、反射定律、色散。

### 电学区（电学实验台）
电池组（1.5–12V）、开关、定值电阻、滑动变阻器、小灯泡、导线（点击接线柱自动连线）。
实测：欧姆定律（U-I 曲线）、串联并联、调光。
实时可视化：电流方向流动动画（导线上的移动亮点）、灯泡亮度、超载警告。

### 波学区（发波水槽）
双源干涉水槽：源间距、频率、波长可调；显示波峰波谷剖面、节线；可单源/双源切换。

### 热学区（量热器）
混合法测比热容：热水+冷水质量、初温可调；实时温度混合曲线、热平衡时间。

### 测量与记录（贯穿全局）
- 3D 卷尺/刻度（台面刻度、立柱标尺）、数显秒表、光电门（周期自动测量）
- 数据表：手动/自动记录（光电门、温度计可自动采样）
- 绘图：选两列散点/折线，线性拟合，显示斜率截距 → 直接支持"g=4π²L/T²"类数据处理

## 4. 关键交互设计

1. **左键**：拾取设备 → 属性面板显示参数；**拖拽**（按住设备本体）：在台面内平移。
2. **设备仓库**：左侧分类树（力学/光学/电学/波/热/测量），点击→设备出现在对应台面默认位置，飞入动画。
3. **视角预设**：工具栏按钮「俯视 / 力学 / 光学 / 电学 / 波 / 热」，相机平滑飞至该区。
4. **暗室模式**：全局环境光调至 5%，光学区局部 spotlight 补光——光线渲染更醒目。
5. **实验指导**：右侧指导书面板，分步 checkbox + 当前实验"一键布置器材"按钮（自动摆放全套设备并设置初值）——降低上手门槛（借鉴 PhET 的 low threshold）。
6. **保存/加载**：JSON 序列化所有设备与参数到 localStorage + 文件下载/上传。
7. **暂停/单步/倍速**：仿真时间控制（0.25×/0.5×/1×/2×）。

## 5. 视觉规范

- 房间 16m×12m×3.6m；地板木纹色 + 环氧台面（青灰色）；区域地毯色带区分学科。
- 每个实验台上方悬挂学科色标牌（力学橙 / 光学紫 / 电学黄 / 波蓝 / 热红），同时是点击聚焦热区。
- 设备选中：天青色描边（emissive 高亮 + 底部选中圈）。
- 字体：system-ui；UI 面板玻璃拟态半透明深色，不遮挡 3D 视野。
